## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/yashkesarwani2004/Python-Scripting-Project.git
```

Go to the project folder:

```bash
cd Python-Scripting-Project
```

Run any Python script using:

```bash
python filename.py
```
